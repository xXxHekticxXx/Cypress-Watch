# Cypress Watch

Android companion app for GloryFit Pro watches (built for the W60 / NAL-WB00), replacing the GloryFitPro app.

- Notifications (calls, texts, any app you pick), quiet hours
- Time, 7-day weather (Open-Meteo, no account), alarms, music controls, find watch / find phone
- Health history (steps, heart rate, sleep, blood oxygen) stored only on the phone, with charts and CSV export
- Watch faces: switch installed faces, install official ones, and 20 Cypress designs built on an official face for your watch

Download the latest **Cypress-Watch.apk** from Releases.

Protocol knowledge comes from the open Gadgetbridge GloryFitPro work, the HT36 project (MIT) and the community
ClockFaceEdit / wfeditor face-format research. Everything is re-implemented here.
